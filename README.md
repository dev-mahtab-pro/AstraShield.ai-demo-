# AstraShield.ai – Agentic AI for Home IoT Security

## Overview
AstraShield.ai is a Proof of Concept (PoC) Agentic AI system designed to
secure home IoT devices using behavior-based anomaly detection and
autonomous defence at the network edge.

## Problem Statement
Home IoT devices lack built-in security and are vulnerable to silent
cyberattacks such as scanning, botnet enrollment, and DDoS staging.
Traditional home routers and firewalls are static and reactive.

## Solution
An Ubuntu-based Universal IoT Hub monitors IoT network traffic using
Scapy/TShark, profiles device behavior, detects anomalies, and
autonomously responds using an Agentic AI decision engine.

## Architecture
IoT Devices → Traffic Monitor → Behavior Profiler → Agentic AI Engine
→ Threat Classifier → Alert & Response → Web/Dashboard Output

## Technologies Used
Python, Ubuntu Linux, Scapy, TShark, Agentic AI, Machine Learning,
IoT, Edge Computing

## Proof of Concept
This PoC demonstrates:
- Real-time traffic monitoring (simulated)
- Behavior-based anomaly detection
- Autonomous decision-making using Agentic AI logic
- Alert and response simulation
